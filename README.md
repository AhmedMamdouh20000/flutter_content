# Flutter Content Studio — 60 posts

Static Arabic RTL website combining 30 morning foundation posts and 30 evening advanced posts. The post cards are included in the HTML as a no-JavaScript fallback; JavaScript adds search, filters, copy/download actions, and local publishing progress.

## Run locally
Open `index.html` in a modern browser.

## Deploy to Vercel
Import this folder/repository as a static site. No build command is required; set the output directory to `.`.

Progress is stored in the browser's localStorage on that device.
